# Professional Portfolio - Vidhyavathi Ramachandran

A modern, responsive, and feature-rich professional portfolio website built with HTML, CSS, and JavaScript.

## 🎨 Features

### Design & Layout
- **Modern Dark Theme** - Professional dark background with vibrant accent colors
- **Responsive Design** - Fully responsive on mobile, tablet, and desktop
- **Smooth Animations** - Subtle animations and transitions throughout
- **Gradient Elements** - Beautiful gradient text and backgrounds
- **Glassmorphism** - Modern frosted glass effects in navbar and cards

### Sections

1. **Navigation Bar**
   - Sticky navbar with smooth scroll
   - Active link highlighting
   - Mobile hamburger menu
   - Brand logo with gradient effect

2. **Hero Section**
   - Eye-catching introduction
   - Floating profile image with animation
   - Call-to-action buttons
   - Social media links
   - Scroll indicator

3. **About Section**
   - Professional summary
   - Key statistics with animated counters
   - Highlight cards with icons
   - Grid layout for better readability

4. **Skills Section**
   - Organized by categories
   - Animated skill progress bars
   - Technology tags
   - Skill descriptions
   - Hover effects

5. **Experience Section**
   - Timeline view
   - Professional journey
   - Company names and positions
   - Period and description
   - Visual timeline line

6. **Projects Section**
   - Project cards with images
   - Project overlay on hover
   - Technology stack display
   - Description and details
   - Hover animations

7. **Contact Section**
   - Contact information
   - Email, phone, location
   - Contact form with validation
   - Form submission feedback

8. **Footer**
   - Copyright information
   - Social media links

## 🚀 JavaScript Features

### Interactive Elements
- **Smooth Scrolling** - Smooth navigation to sections
- **Mobile Menu** - Responsive hamburger menu
- **Scroll Animations** - Elements fade in on scroll
- **Counter Animation** - Statistics count up on view
- **Skill Bar Animation** - Progress bars animate on scroll
- **Form Validation** - Email and message validation
- **Notifications** - Toast notifications for form feedback
- **Scroll to Top** - Floating button to jump to top
- **Active Link Highlight** - Nav links highlight current section
- **Parallax Effect** - Hero section parallax on scroll
- **Lazy Loading** - Images load as they come into view
- **Keyboard Navigation** - Escape key closes mobile menu

## 🛠️ Customization

### Change Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... more colors ... */
}
```

### Update Content
1. Edit `index.html` to update text, skills, and experience
2. Replace `vidyavathi_mam.jpeg` with your profile image
3. Update social media links in hero and footer sections
4. Modify contact information in the contact section

### Add Projects
Add new project cards in the projects section following the existing structure.
